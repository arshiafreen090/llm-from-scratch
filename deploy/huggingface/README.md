# TinyLLaMA

A small LLaMA-style language model (RoPE, RMSNorm, SwiGLU, GQA), pretrained and
instruction-tuned from scratch on children's stories. Ask it for a story and name a few
words it should use.

- **Chat UI**: this page
- **OpenAI-compatible API**: `https://<this-space>.hf.space/v1` works with the official
  OpenAI libraries (click **API** in the page for ready-to-copy code)
- **Code, training runs and results**: https://github.com/arshiafreen090/llm-from-scratch
