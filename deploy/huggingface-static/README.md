# TinyLLaMA, running in your browser

An 11M-parameter LLaMA-style language model (RoPE, RMSNorm, SwiGLU, GQA), pretrained and
instruction-tuned from scratch on children's stories. This page downloads the model (11 MB)
and runs it **in your browser** with ONNX Runtime Web: nothing you type is sent to a server.

- **Model files:** https://huggingface.co/afeening/tinyllama-from-scratch
- **Code, training runs and results:** https://github.com/arshiafreen090/llm-from-scratch
