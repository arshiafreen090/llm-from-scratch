What story should I write?

An 11M-parameter LLaMA-style model, pretrained and instruction-tuned from scratch on children's stories. Ask for a story and name a few words it should use.

Each message is answered on its own · Enter to send, Shift+Enter for a new line

Use this model from your own code

On this page the model runs inside your browser (ONNX Runtime Web), so there is no server to call. To get the HTTP API, run the model's own server, on your computer or any machine with Docker. It speaks the OpenAI chat API, with optional API keys and rate limits:

git clone https://github.com/arshiafreen090/llm-from-scratch.git && cd llm-from-scratch
docker build -t tinyllama . && docker run -p 8000:7860 tinyllama
# then: OpenAI(base_url="http://localhost:8000/v1", api_key="any-text")
